# Simulação de Projeto SCRUM — Análise de Dados

Repositório criado para a atividade prática **Simulação de Projeto SCRUM** do bootcamp da Generation Brasil, com foco na aplicação de metodologias ágeis em um fluxo de análise de dados

## Objetivo
Simular o ciclo de trabalho de uma equipe de dados utilizando o GitHub como ambiente central de versionamento e gestão de tarefas, passando pela configuração do quadro ágil, integração de ferramentas de análise, planejamento e execução de um Sprint
## Ferramentas Utilizadas
* **Controle de Versão e Gestão:** GitHub e GitHub Projects (quadro Scrum/Kanban)
* **Análise de Dados:** Google Colab
