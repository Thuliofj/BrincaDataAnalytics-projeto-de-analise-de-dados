# Simulação de Projeto SCRUM — Análise de Dados

Repositório criado para a atividade prática **Simulação de Projeto SCRUM** do bootcamp da Generation Brasil, com foco na aplicação de metodologias ágeis em um fluxo de análise de dados[cite: 1, 2].

## Objetivo
Simular o ciclo de trabalho de uma equipe de dados utilizando o GitHub como ambiente central de versionamento e gestão de tarefas, passando pela configuração do quadro ágil, integração de ferramentas de análise, planejamento e execução de um Sprint[cite: 1, 2].

## Ferramentas Utilizadas
* **Controle de Versão e Gestão:** GitHub e GitHub Projects (quadro Scrum/Kanban)[cite: 1]
* **Análise de Dados:** Google Colab / Jupyter Notebook / Google Sheets *(ajustar conforme a escolha da equipe)*[cite: 1]

## Estrutura do Ciclo de Trabalho
* **Registro de Produto (Product Backlog):** Organização das etapas de limpeza de dados, análise exploratória e visualização[cite: 1].
* **Planejamento de Sprint:** Seleção e priorização das tarefas viáveis para o ciclo[cite: 2].
* **Execução e Acompanhamento:** Movimentação das entregas entre as colunas *Pendente*, *Em Andamento* e *Pronto*, com reuniões diárias (*Daily Scrum*) e revisão final (*Sprint Review*)[cite: 2, 3].
